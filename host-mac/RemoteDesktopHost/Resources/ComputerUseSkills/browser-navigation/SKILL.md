Navigate to a URL supplied in the user's task or accepted clarification. Inspect the current browser view and address field. When the address field is focused and empty, enter the exact URL; otherwise focus it with Command+L, observe again, and replace old text after confirming full selection. Verify the complete typed URL before submitting. Press Enter as a separate action, then observe the resulting page and URL. Take a fresh observation after each action. If a permission dialog or sign-in blocks progress, describe it and ask the user to resolve it. Report progress from the observed page.
