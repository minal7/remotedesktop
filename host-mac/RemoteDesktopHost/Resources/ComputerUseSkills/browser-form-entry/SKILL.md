name: browser-form-entry
description: Enter requested form values and verify the complete task.
metadata:
  audience: default-browser-control
  required-tools: computer_use
---
Identify the next unfinished requested field from the current page and enter its exact requested value through the focused control. Observe the value after entry. For a combobox, commit the exact displayed choice or use one Tab step, then verify it is collapsed and committed before moving to another field. Move between unfinished fields one at a time and keep all remaining task conditions in completion criteria. Use displayed account details when the task names that account and the value is clear; ask one focused question when a choice remains ambiguous.

For an email draft, fill the requested recipients, subject, body, and attachments, then verify the saved draft is open. Send only when the user explicitly requested sending; host approval governs delivery. Preserve each requested value exactly.
