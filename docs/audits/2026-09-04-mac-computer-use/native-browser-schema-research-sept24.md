# Native tool schema research (pinned llama.cpp)

Checked primary source revision `6eddde06a4f25d55d538b5d15628dcc2b6882147` (the app's pinned b9992 runtime). No app/source/build/model work was performed during this research.

- **Tool schemas do constrain generated arguments on the supported template path.** In `common/chat-auto-parser-generator.cpp`, required tool choice opts into grammar generation and makes it eager; the PEG tool parser passes each function's `parameters` to `p.schema(...)`. For JSON-tagged tools, `tool_choice == REQUIRED` keeps the call mandatory; with `parallel_tool_calls=false`, the parser emits one call. This is conditional on the loaded chat template advertising tool-call support and the request using the `--jinja`/auto-PEG path. See [grammar selection and required mode](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/chat-auto-parser-generator.cpp#L81-L99) and [schema-wrapped tool arguments](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/chat-auto-parser-generator.cpp#L318-L363).
- **Anchored patterns compile to grammar.** The schema converter requires `^...$`; ordinary capturing groups are processed as grouping, while lookaround syntax is explicitly unsupported. The selected evidence-item pattern is `^(source|((text|tooltip):)?t[0-9]+|(link:)?l[0-9]+)$`. It permits source, the established bare record aliases, and their canonical prefixed forms while rejecting malformed forms such as `link:https://...`. Pattern support is implemented at [`_visit_pattern`](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/json-schema-to-grammar.cpp#L348-L352); group/alternation/repetition parsing is visible [here](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/json-schema-to-grammar.cpp#L412-L489), and string-pattern dispatch [here](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/json-schema-to-grammar.cpp#L961-L963). The converter does not establish that a syntactically valid ID exists in this capture.
- **No tool-level `strict` switch is needed or evidenced.** The pinned `common_chat_tool` contains only name, description, and parameters; native grammar construction consumes the `parameters` schema. Do not rely on `strict: true` to activate enforcement. See [tool and template input structs](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/chat.h#L217-L260).
- **Local `$defs` refs are supported, with a measurement caveat.** The auto-parser resolves tool parameter refs before grammar creation, and the schema converter resolves `#/...` local pointers and reuses named rules. This supports hoisting a shared enum/schema rather than serializing it repeatedly. It may lower schema bytes in the prompt, but grammar expansion/compilation has its own cost; measure exact input tokens and runtime behavior. Avoid remote refs in the offline product. See [tool-ref resolution before grammar construction](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/chat-auto-parser-generator.cpp#L88-L99) and [local ref resolution](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/json-schema-to-grammar.cpp#L626-L637) and [local pointer resolution](https://github.com/ggml-org/llama.cpp/blob/6eddde06a4f25d55d538b5d15628dcc2b6882147/common/json-schema-to-grammar.cpp#L761-L816).

**Limit:** grammar constrains syntax and schema membership only. It does not prove evidence relevance, claim entailment, completeness, current-page freshness, source semantics, or goal completion. Normalize any accepted bare alias only through an exact host mapping to a current reference; retain the existing host evidence, answer-claim, UTF-8, reference, completion, freshness, and cancellation checks. Grammar/template behavior still needs focused qualification against the exact bundled model/template; this source review alone is not that qualification.
