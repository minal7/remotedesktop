# Delivering observed research findings without losing the original task

Source checkpoint, 2026-09-08. Implementation and regression sources are prepared; execution remains deferred.

## First-principles problem

A browser action is useful only if it advances the person's requested outcome. Reading listings and then returning a generic pause discards useful work from the person's view. But a model choosing a listing, a page loading, or a quoted price satisfying a numeric comparison does not prove a complete travel/concert/movie answer. The app needs separate states for observed passages, verified offer facts, unresolved requirements and whole-task completion.

The driver previously returned only its generic intervention when link selection returned no next choice. The current native candidate batch already retained the source text and original requirement fragments. Simply putting those findings in the existing intervention message would silently truncate them to 500 characters. Sending them as an assistant envelope would terminalize the pending phone prompt and break Resume.

## Source repair

- [Report assembly](../../../host-mac/RemoteDesktopHost/ComputerUse/ComputerUseBrowserResearchReport.swift) preserves whole candidate passages, including text that neither model classified, and surrounding native page text. Every original requirement fragment remains in the pending ledger. All page lines are visibly quoted. No offer, availability, result-count or completion claim is created from model grouping or scalar comparisons.
- [Native preparation](../../../host-mac/RemoteDesktopHost/ComputerUse/ComputerUseBrowserResultCandidates.swift) validates the exact current reading, goal revision and answer-source policy before and after assembly. Selected details links come from native observed anchors and are checked without opening them. Unsupported or excluded links are omitted; current-page, authentication and cancellation failures prevent publication. Native callbacks are joined before the research owner releases its operation slot.
- Exact HTTP(S) addresses without credentials, query or fragment may be displayed, bounded to 2,048 UTF-8 bytes. A rejected address is omitted, never rewritten into another resource. This is a conservative export-format rule, **not proof that a URL is public, secret-free, relevant or independently accessible**. All source links are literal, copyable text; no page-authored Markdown link or action is executed.
- The display budget is 16 KiB, with at most eight whole passages and 4 KiB per passage. The complete requirement ledger and surrounding context are reserved first. Oversized passages are omitted with a notice. If the complete context/ledger plus a passage cannot fit, the driver retains the existing incomplete-task handoff. It does not truncate a requirement or claim a complete result set. Reading omissions are explicit.
- The [research owner](../../../host-mac/RemoteDesktopHost/ComputerUse/ComputerUseBrowserResearchTask.swift) prepares the report under its existing operation/ownership boundary. The [driver](../../../host-mac/RemoteDesktopHost/ComputerUse/ComputerUseBrowserResearchDriver.swift) now returns a typed partial-report result after a fresh reading with no next link. The capability executor and host recheck the retained owner, execution ID, goal revision and reading identity before accepting it.
- The [host manager](../../../host-mac/RemoteDesktopHost/ComputerUse/HostComputerUseManager.swift) persists the ordinary local pause and sends a status, retaining the exact prompt and execution owner. A separate optional `researchProgress` payload carries the full findings. Its report ID binds root, goal, reading and output text. An accepted duplicate prompt replays the same cached report without planning, reading or navigation. Resume clears that delivery cache and refreshes the task normally. Failed pause persistence withholds the report. Queued report delivery uses the existing transport/authorization generation fence.
- The [shared protocol](../../../protocol/Swift/ComputerUseProtocol.swift) validates the report digest and UTF-8 budget. Reports require an ordered intervention with both control clocks, and cannot accompany clarification references or historical-action-only updates. Older clients still receive the short pause guidance. Current clients reject report payloads on assistant envelopes.
- The [phone model](../../../ios/RemoteDesktop/ComputerUse/ComputerUseSessionModel.swift) accepts findings only after host/session, task and control-clock admission. Repeated delivery creates one literal chat bubble per report ID. The active prompt, pause and Resume control remain intact. Report bubbles cannot become assistant-question context for a new planner request. The [phone view](../../../ios/RemoteDesktop/ComputerUse/ComputerUseView.swift) renders literal text and allows selection/copying.
