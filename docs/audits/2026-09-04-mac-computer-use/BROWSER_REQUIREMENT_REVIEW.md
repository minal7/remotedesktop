## First-principles finding

An offer can be internally coherent and still be wrong for the request. For example, a single concert with a USD 40 quote could be in the wrong city, on the wrong date or unavailable for the requested party. The existing semantic review examined candidate/field association and price qualification. It received the full user text but had no explicit output for whether each offer addressed each requirement. The next-action planner received native scalar comparisons and general semantic uncertainty, without a cited explanation of which requirement needed more evidence.

A useful next-action decision needs a complete matrix: every candidate against every original requirement, including contradictions and unanswered conditions. That matrix must retain the original meaning and observed citations. A model's favorable judgment is still an interpretation, not independent offer verification or a completed answer.
