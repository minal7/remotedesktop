# Soft keyboard focus and capture lifetime

Source repair, 2026-09-10, following `442f65a`. Native/UI/test/model execution remains deferred. Complete browser/login handoff and natural-language task correctness remain unqualified.

## First-principles findings

Binding a text field to a session does not establish that the user is typing into it. The prior soft capture obtained a remote input source while windowless, and `canSendInput` checked the source but not actual first-responder/window ownership. Its resignation override discarded composition while leaving that source usable. A later `insertText`, Return or Delete could therefore still address the Mac after native focus had moved elsewhere. The SwiftUI update path also attempted to reclaim focus whenever the field was no longer first responder.

Apple's [focus contract](https://developer.apple.com/documentation/uikit/uiresponder/becomefirstresponder()) says a focus request can fail and should target a view in an active hierarchy. Software keyboard visibility and hardware key delivery depend on the key window. [Resignation](https://developer.apple.com/documentation/uikit/uiresponder/resignfirstresponder()) is a lifecycle boundary, and [editing-ended notification](https://developer.apple.com/documentation/uikit/uitextfielddelegate/textfielddidendediting(_:)) follows native focus loss. These contracts support the changes below; they do not prove every UIKit callback sequence or system dialog behavior.

The existing fixture objects also exposed a weakness in the evidence: they sent input from unattached fields. Such a case can exercise text encoding and composition methods, but cannot establish that production input belongs to the active native field. The fixtures must satisfy the production focus requirement before testing committed text.

## Source changes

[KeyboardCapture](../../../ios/RemoteDesktop/Session/KeyboardCapture.swift) now stores session/capture identity at binding and acquires its soft-keyboard source only after `super.becomeFirstResponder()` succeeds. It rechecks actual native focus, the same key window, session/identity and exact source after potentially reentrant acquisition. Every text send and each half of a key pair rechecks those conditions. A covered root presentation or stale source denies delivery.

One native field owns one focus/source lifetime. Resignation, editing end, window detachment/change, key-window loss, scope change, explicit dismissal and teardown permanently retire that field. Retirement closes authority and discards provisional text before native resignation can generate another commit. It releases owned keys and, while still the current capture under the same identity, latched soft modifiers. It cannot release a successor's source or modifier ownership. Rebinding or calling `becomeFirstResponder()` on the retired object cannot restore input; reopening installs a new field.

The wrapper no longer holds an untracked focus task or retries focus on every update. The field owns one cancelable initial request. That request records the exact window and weak originating responder; it cancels if a different local responder has appeared or the original has disappeared before delivery. This reads ownership, not text. A direct successful focus attempt cancels the pending request.

Native focus loss schedules a bounded, deferred dismissal so the parent can close its keyboard control without mutating SwiftUI state during a view update. That callback requires the exact active field, session, capture identity and request token. A replacement capture cancels old pending dismissal work, and an old accessory action cannot hide the replacement. Explicit accessory dismissal retains its immediate callback after rechecking ownership.

Source retirement and text delivery can invoke external callbacks. Key-pair delivery now rechecks native ownership before each event. If focus moves after a key-down, cleanup releases that owned key, and the old function cannot send a second release or later text. The existing composition/committed-text distinction remains in place.
