## Probe constraints and interpretation

Use the existing local target: 4 GiB worker cap, shared 45-second deadline, four inference threads, at most two requests, and existing context/output caps and request limits. Do not retain raw reasoning or feed it into follow-up context. The authors' [QuickStart at the pinned source commit](https://github.com/OpenBMB/AgentCPM/blob/4a43561e790c154292798b3edd50171f71241cec/AgentCPM-Explore/quickstart.py) instead uses temperature 1, top-p 1, 4096 output tokens, 30 interactions, and passes thoughts back to the model. Those are author-evaluation settings, not targets for this compatibility screen. A 4B thinking model may exceed the local latency budget; measure under the unchanged local caps.

Preserve task meaning and tool descriptions. Mechanically adapt only the schema rendering and call parser to AgentCPM's documented protocol, and record the adapter. For the September 24 native-function replay, archived HTTP request bodies are exact copies of the source requests, including `enable_thinking=true` (their SHA-256 values match). The model's embedded chat template renders those same API messages into model-specific prompt tokens. Semantic prompt edits would confound attribution. A miss alone does not establish either a model or harness defect. Upstream results concern mostly deep-research/web tasks and do not validate Mac UI, native operations, interactive clarification, handoff, or interruption recovery. Those source claims do not establish performance in this app.

Exclude **Salesforce/xLAM-2-3B-fc-r** from production candidates because its model card specifies CC-BY-NC-4.0 and research-only use, despite its stronger direct function-calling fit. See its [official card](https://huggingface.co/Salesforce/xLAM-2-3b-fc-r).

The durable [native replay result](native-browser-agentcpm-results-sept24.json) includes the full model pin, exact request bodies, sanitized calls, and resource measurements.

The additional production-schema replay used the unchanged archived request bytes (`enable_thinking=true`; SHA-256 `cd079d4b2d6403f537332fb700dbb786656ae12b34c976ddf18f298c91c98eeb`). In 12.61 seconds it returned a `search` with nonempty reference `l15` and visible title text; all three requirements remained pending. This is code-review-invalid for the retained-step decoder because search cannot carry a reference, though no Swift decoder replay was run. Peak sampled process memory was 3.23 GiB under the 4 GiB worker cap. No browser/MCP calls occurred. This result adds a production-schema failure to the separate useful native-function discovery / failed city-clarification comparison; AgentCPM is not a qualified replacement.
