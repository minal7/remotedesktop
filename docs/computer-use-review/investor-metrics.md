## Product and privacy

Computer Use is **Beta** and uses the local **Fara 1.5-4B** model. The measured test Mac was an Apple M2 Max with **32 GiB** memory running macOS 27; the **16 GB** figure is the product minimum, not the measured RAM. ([test-machine hardware record](../../build/eval/report-prep/test-mac-hardware-20261020.json)) Inference runs on the Mac. Prompts, results, controls, and approvals travel between the phone and Mac over authenticated LAN TLS; screen sharing and remote input use WebRTC. Local inference does not mean zero network transmission. ([model manifest](../../host-mac/RemoteDesktopHost/ComputerUse/ComputerUseArtifactManifest.swift), [product overview](../../README.md), [privacy details](../privacy.html))

Distillation from recorded episodes, away mode, and extensions are future directions, not shipped capabilities. ([plan](</Users/michael/Documents/ChatGPT/remote desktop/docs/computer-use-review/investor-demo-plan.md>))
